# 设计说明

## 动态编排

`Engine._run` 中的 while 循环每轮先处理数据库中未完成的工具调用，再组装上下文并请求模型。模型返回工具调用时，保存 assistant 消息后逐个校验/执行，把结果保存为 tool 消息；模型返回文本时结束。模型正文增量先形成持久化事件，SSE 向网页实时推送；工具参数必须完整收齐且流正常结束后才交给工具层执行。工具顺序不由业务分类分支预先写死。`ScriptedDemo` 仅是测试替身，不能把它的规划算成真实模型能力。

状态包括 ready、running、waiting_approval、completed、completed_unverified、provider_error、budget_exhausted、stopped、failed。审批不是模型工具：只能经本机 CLI/API 的用户操作提交。当前未使用 LangGraph interrupt。

追加问题沿用 session，保留历史与工作笔记，增加本轮步数额度。审批未结束时禁止追加。完整历史留在 SQLite，发送给模型的是裁剪后的投影。

## 上下文

固定规则、原任务、四类技能的元数据，加上有界工作笔记构成系统消息；较旧结果只保留短摘录，最近历史按完整的 assistant/tool 交互组保留。避免只留下工具结果而丢失对应 tool_call。单个交互组过大时明确报错，不静默破坏协议。

默认 18000 字符预算只覆盖组装的 messages，不包括另外发送的工具 schema，也不是精确 token 计数。工作笔记最大 2500 字符；工具结果序列化后超过 4500 字符外置为会话产物，并返回预览与 ID。回读每次最多 4000 字符，归属从 SQLite 查询，不通过用户输入的 ID 字样授予权限。数据库原历史不会因投影裁剪被删除，没有 LLM 自动语义摘要。

Skills 元数据进入提示，正文按需加载；它可以建议先读测试再修改，但不能改变路径规则或批准状态。仓库文本和工具输出视为不可信数据；提示词约束不能消除所有注入风险，真正的写入授权位于工具执行代码。

## 修改与恢复

提案记录原文、替换后内容、diff、前后 SHA-256。批准仅绑定这个会话与提案。应用时再次检查路径与原文哈希，通过后以临时文件 + os.replace 原子替换。文件被用户改动则拒绝过期提案。同一提案已落盘且内容一致时可识别重放。

调用结果先持久化再补写对话，恢复时优先重用已记录结果。对于执行中断的测试调用不盲目重跑，反馈结果未知，要求重新检查。没有宣称任意外部工具 exactly-once。文件系统操作与 SQLite 之间不是分布式事务；同机其他程序的恶意并发替换不在安全保证内。

## 预算、故障与执行

默认每个任务 20 步，每步最多 8 个工具调用；单次 run 轮间检查 180 秒预算，API 报告的累计 total_tokens 达 50000 后不再请求模型。不是实时硬截止，也不能限制已发出的请求产生的费用。HTTP 请求超时 30 秒，429/指定 5xx/网络超时有限重试，鉴权错误直接失败。相同工具参数连续失败三次停止。

停止是协作式停止，不会立即中断已经发出的网络请求或正在执行的测试。单次测试等待 30 秒，超时尝试清理进程树；执行输出截取前 100000 字节。临时输出文件在进程结束前不限制磁盘用量，不应用于恶意仓库的宿主机执行。

测试只允许预置 unittest/pytest 命令，不接受任意 shell。默认 disabled；trusted-local 仅供可信代码，剥离常见模型密钥环境变量、使用 Python 隔离启动，但依然有本机文件和网络能力。Docker 配置无网络、只读仓库/根文件系统、资源限额和非 root 用户；默认镜像支持 unittest，尚未做本机 Docker 实测，镜像标签未锁定 digest。

工具返回的测试状态独立于模型最终文字。每次代码修改使之前的验证失效，发现 0 个 unittest 不算 passed。项目暂不内置隐藏测试、防模型篡改测试策略或完整性能基准，测试通过也不能证明补丁完全正确。

## 下一阶段

优先扩展真实模型任务集并固定模型版本、提示与成本记录；随后完善独立验收测试、Docker 实机用例及镜像固定。只有实际需要并发时再增加跨进程租约与任务队列。MCP、多 Agent、自进化记忆均不作为当前实现能力。

## 网页会话与流式传输

登录将启动密码换成进程内随机会话 Cookie，HttpOnly、SameSite=Strict，并检查 Origin / Sec-Fetch-Site。仍为本地单用户，不是多租户身份系统。SSE 接口与普通 API 采用相同鉴权，Last-Event-ID 可续接数据库事件；网页不会每秒重新拉取整个会话。模型流遇到截断时不执行未完成参数，已产生增量的请求不会自动重试。

网页调度器限制同一工作区同时只有一个任务执行；审批接口以数据库条件更新防重复提交，当前等待审批的操作获决定后自动续跑，包括运行尚未退出时的短暂竞争窗口。停止仍为协作式，不保证立即终止外部请求。
