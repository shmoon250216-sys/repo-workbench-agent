# Repo Workbench：项目描述与证据

Python｜FastAPI｜Function Calling｜Skills｜MySQL｜SQLAlchemy｜Pydantic

- **任务闭环：**通过 Function Calling 驱动 11 个受限工具，并按需加载 4 类 Skills，将代码理解、修改提案与测试反馈串成执行闭环；结合步数预算、有限重试和重复失败终止，限制无效循环。
- **上下文保护：**通过结构化需求提取、原文来源索引与增量更正，缓解长对话裁剪丢失目标和约束的问题；完整保留工具交互组，长输出外置并分段回读，支持摘要存疑时回查原始要求。
- **执行审批：**通过 diff 审核与 SHA-256 校验阻止过期提案覆盖文件；将测试授权绑定代码指纹、命令和运行环境，规格变化重新审批，条件更新保证同一授权仅能领取一次。
- **事务与恢复：**通过 MySQL 独立消息表、会话版本检查和短事务，防止旧状态覆盖及工具结果与对话记录不一致；故障注入验证消息、结果和状态共同回滚，重连后可恢复待审批任务。
- **验证与交付：**通过 SQLite/MySQL 双后端契约、并发领取与网页接口回归验证上述机制：129 项测试中 128 项通过、1 项权限限制跳过；8 个离线集成场景通过，覆盖修改、审批拒绝及测试执行。
