# Repo Workbench：项目描述与证据

AI 协作个人项目；自定义 Python 编排，不宣称 LangGraph、模型训练或生产部署。

- **双模式编排：**通过 ReAct 与 Plan-and-Execute 两种模式适配简单和多步骤任务，串联 12 个受限工具与 4 类 Skills；计划按步骤验收并持久化，避免审批恢复后重复规划，缺失证据时不直接判定完成。
- **上下文与复盘：**通过结构化需求提取、原文回读和工具交互组裁剪保留用户约束；任务结束生成有界反思，仅将具备通过测试证据的经验写入长期存储，按工作区召回至多 3 条，让处理记录可跨会话复用。
- **执行边界：**通过 diff 审批、SHA-256 与执行规格绑定，防止过期提案覆盖文件或授权被重复使用；测试后再次核对工作区指纹，避免代码已变化仍沿用旧的通过结果。
- **持久化恢复：**通过 MySQL 独立消息表、会话版本号和短事务，防止旧状态覆盖及工具结果与对话记录不一致；计划、审批和调用状态可恢复，跨会话经验设置容量、有效期及删除接口。
- **测试验收：**构建 4 类自建仓库任务，真实调用 DeepSeek 并以独立断言对照两种模式，各 4/4 通过，同时记录 Token 与耗时；154 项机制测试中 153 项通过、1 项权限限制跳过，8 个离线集成场景通过。

材料为自建合成仓库，真实模型执行；4 类任务小样本，不能外推企业任务成功率或宣称规划优于 ReAct。经验复用减少重复探索是设计目标，当前仅验证召回有效，尚无统计显著收益。

证据：[双模式设计](planning-and-reflection.md)、[真实模型对照](../evaluation/planning-summary.md)、[机制回归](../evaluation/plan-reflection-regression.json)。

- **可选混合记忆：**通过经验读写开关控制跨任务复用，以BM25＋本地BGE向量＋RRF替代词项交集；16条有目标合成查询Recall@3从62.5%到100%，向量缓存随经验持久化，缺失模型时降级BM25。

新增证据：`evaluation/memory-results.json`、`evaluation/memory-regression.json`。4条无关查询返回空，但2条冲突查询仍误召回；不宣称适用性判断或任务成功率改善。
