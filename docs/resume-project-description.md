# 项目描述与证据口径

Repo Workbench｜代码开发与验证 Agent
      github.com/shmoon250216-sys/repo-workbench-agent
    
    
      Python｜FastAPI｜Tool Calling｜Skills｜Pydantic｜SQLite
      
        任务执行：面向本地仓库的代码理解、功能修改和缺陷修复，实现模型与工具交替执行的 Agent Loop；提供读取、搜索、修改提案和测试等 10 个工具，通过执行结果反馈支持后续决策。
        技能与上下文：设计 4 类 Skills，提示中保留目录、按需加载正文；按完整工具交互组裁剪历史，保留任务与工作笔记，将长输出外置并按会话分段回读，避免工具结果持续占满上下文。
        修改与权限：以 Pydantic 校验工具参数，限制文件访问范围；拆分修改提案与执行，通过网页审核 diff，获批后核对原文 SHA-256 并原子替换，拒绝过期提案及跨会话调用审批。
        恢复与兜底：用 SQLite 保存会话、工具结果及审批，支持暂停恢复与多轮追加；设置有限重试、步数预算和重复失败终止，将实际测试结果与模型答复分开记录，修改后使旧验证失效。
        验证：43 项自动化测试中 42 项通过、1 项受本机权限限制跳过；构建 8 个离线集成场景，验证文件修改、审批拒绝和测试执行，并完成网页审批、刷新恢复及移动端检查。

代码由 AI 协作开发。工具循环支持真实模型接口，当前结果来自离线机制验收；模型 API 待本地配置后单独验收。未宣称线上生产、真实用户收益、模型修复成功率或 Docker 实机隔离效果。参考 MiniCode 架构理念，Python 运行时独立实现。
