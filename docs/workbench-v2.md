# 工作台使用与升级验收

1. 打开启动链接自动登录；手动登录时填写工作台访问密码。API Key 仅保存在模型环境配置中，不填到登录页。
2. 左侧“新建开发任务”开始新会话，中间输入目标并发送即开始执行。已有会话直接发送追问。
3. 正文逐步出现，右侧展示工具开始、返回、上下文准备等事件。展开事件查看细节。
4. 右侧审核 diff，点击“批准并继续”后自动运行。“拒绝并反馈”也会自动将拒绝结果交给模型处理。
5. 以实际测试状态判断是否通过，不能只看模型自述。刷新会保留浏览器登录和当前会话。
6. “停止”为协作式停止；正在执行的请求或工具可能需要结束后才停止。

本轮新增 8 项回归，覆盖流式文本/参数组装、截断、Cookie 登录退出、跨站请求、审批自动继续和 SSE 事件游标。浏览器使用延迟流式替身验证文字确实在任务完成前出现，结果记录在 evaluation/browser-results.json。真实 DeepSeek 只读任务完成 2 步，产生 9 条持久文本增量，见 evaluation/live-stream-results.json；它与离线测试分别记录。

当前仍为本地单用户系统。登录页改进并不意味着已实现账号注册、密码找回、租户隔离或生产身份管理。
